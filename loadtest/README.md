# Pruebas de carga

Carpeta reservada para los artefactos de pruebas de carga, que se exigen **desde la Entrega 2** (lineamientos, sección 7):

- scripts de los escenarios (la herramienta se define en el plan de pruebas);
- *seed* de datos parametrizable, para que cada corrida parta del mismo estado;
- resultados crudos de cada ejecución (al menos tres por escenario).

El plan de pruebas y el análisis de resultados se documentan en la Wiki, en la página de cada entrega.
